# Security Policy

VAOS is a governed agentic platform. Security controls are architectural, not optional.

## Mandatory controls

- Principle of least privilege
- Capability-scoped agent authority
- RBAC/ABAC enforcement
- Boundary validation for external data
- Secret isolation from source control
- Tamper-evident audit records
- Human approval for high-risk actions
- Sandboxed execution for computer/tool use
- Idempotency for retryable state changes

## Reporting

Security findings should be handled privately until triaged and remediated.
