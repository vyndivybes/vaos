Evidence interpretation and date-window limitations

Only the existing governed 90-day snapshot is available. Work status is the current recorded state for a work package whose last update falls inside the chosen window, not a reconstructed historical status or a dated completion event. A reviewed audit or verified report is counted only on its event timestamp. Registration, training fixtures and technical PASS labels do not prove productive business output. A forecast is shown only if independently qualified; no fictitious productivity or delivery dates are generated.
