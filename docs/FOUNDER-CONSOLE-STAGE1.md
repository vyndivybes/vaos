# Founder Command – Stage 1 (preparation only)

Responsive standalone-oriented console linked from the workspace. Sixteen roles selectable, read-only /api/langgraph agent state, read-only /api/missions lookup, and locally prepared instruction/report/override-proposal drafts.

**Not yet operational:** live agent conversations, submitted direct instructions, founder-authorized overrides, speech input, push notification, scheduled PDF reports, cross-device message persistence. No new business write, credential, L5 permission, Worker toggle, service worker or private-data offline cache is introduced. All drafts say DRAFT_NOT_SENT.

## Future qualification

1. Authenticated founder-role authority plus time-bounded, immutable direct-message persistence, audit and anti-replay.
2. Route direct commands to qualified agents through existing mission contracts and L0–L5 gates, with independent verification and segregation of duties.
3. Evidence-backed executive reports and delivery channels.
4. Windows/Android/iOS PWA install and accessibility E2E tests, logout/session invalidation, voice and push qualification.
5. Isolated preview, CI regression, authenticated live readback and negative authorization tests before production merge/deployment.
