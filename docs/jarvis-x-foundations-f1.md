# VAOS JARVIS X — Evidence Graph, Review Optimization and Governed Coordination (F1)

Date: 2026-10-13. Scope: **founder-only supervised decision-room preview**. This is a **bounded functional foundation**, not a production knowledge-graph service or manufacturing optimization certification.

## What F1 actually does

1. **Transient source-status graph.** An authenticated founder may ask VAOS a read-only question. The existing bounded adaptive reader verifies authoritative source records from VYNDI OS, VEDM and VIBPE. F1 constructs up to three source-domain nodes with observed/HOLD status and exact verified source-authority names. Static cross-domain graph edges are marked `UNVERIFIED_DEPENDENCY_HYPOTHESIS`; they are *not* proven causal links. The graph is built per response, with no persistent vector index, database migration or exposure of raw ledger, customer, engineering or personnel records.
2. **Exact bounded combinatorial review optimizer.** From the observed domain nodes alone, F1 generates an abstract review-task set (maximum three) and exhaustively evaluates feasible subsets under a hypothetical **two-review-slot** limit. Priority weights are fixed `HEURISTIC_REVIEW_PRIORITY_ONLY` values, not learned risk probabilities, actual staff hours, money, inventory or manufacturing capacity. It provides a suggested order of fact-verification work, **not** a six-month production or cash forecast. Zero observed sources → HOLD and no tasks chosen.
3. **Proposal-only cross-function coordination.** The selected source domains are associated with possible specialist review roles and reversible next checks. `qualification=UNVERIFIED`, `assignment=NOT_DISPATCHED`, `dispatchedAgents=0`. Neither MCP/A2A messages nor mission/job execution occurs. The existing agent supervisor and L0-L5 qualification policies remain authoritative.

## Entry point and behavior

Existing authenticated founder endpoint `GET /api/adaptive-intelligence?q=...&eval=v3-readonly&mode=jarvis-x`, used by the existing Ask VAOS adaptive toggle. It returns the same independently checked advisory as before, with an added `jarvisX` object and a clearly labeled `JARVIS X SIMULATION` or `JARVIS X HOLD` text summary. An unknown mode or unaccompanied mode is rejected (422). Unauthenticated requests continue to receive 401. The old adaptive route without mode remains unchanged. No new microphone, speaker, paid provider or browser library dependencies are required.

## Strict limits

- Same existing **three maximum authorized source reads** and three total AI calls per UTC day shared voice quota; **zero extra AI calls** for F1.
- No unrestricted internet research, no new tools, no external model API, no model fine-tuning and no OpenAI API billing.
- No change to roles, policy controls, business transactions, engineering releases, company ledgers or Cloudflare Durable Object namespaces.
- A source-status graph is not GraphRAG, a heuristic review optimizer is not OR-Tools CP-SAT, and a proposal list is not A2A task delegation.
- No claim that financial capacity, manufacturing delivery, cost, supplier lead times or engineering qualification are proven from three summaries.
- Scenario priorities are policy examples, not measured severity or confidence. Full V3 autonomous cutover remains HOLD.
